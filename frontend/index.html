    Enable Location Access

    Location access is blocked. To center the map and plan routes from your current position, please enable location in your browser settings.

    Option A: Website Settings
    1. 1 Tap the aA icon in the address bar.
    2. 2 Select Website Settings.
    3. 3 Change Location to Allow.
    Option B: iOS System Location Services (If blocked)
    1. 1 Open iPhone Settings ➔ Privacy & Security ➔ Location Services.
    2. 2 Ensure Location Services is toggled ON.
    3. 3 Scroll down, tap Safari Websites, and select While Using the App.
    Option A: Chrome Site Settings
    1. 1 Tap the lock / settings icon left of the URL.
    2. 2 Select Site Settings or Permissions.
    3. 3 Set Location to Allow.
    Option B: Android System Permissions (If blocked)
    1. 1 Open Android Settings ➔ Apps ➔ Chrome.
    2. 2 Tap Permissions ➔ Location.
    3. 3 Select Allow only while using the app and enable Use precise location.
